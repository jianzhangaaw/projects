# 《机器学习实践》大作业 —— 实验方案（内部设计稿，不提交）

题目：Spaceship Titanic 乘客传送预测（二分类）

## 数据

- 来源：Kaggle 竞赛 Spaceship Titanic 的 train.csv / test.csv，经公开镜像获取，
  四份独立副本（GitHub×2、HuggingFace×2）逐字节一致，核对脚本 `checks/check_data.py`、
  `checks/cross_source.py`，证据存档在 `checks/evidence/`。
- 规模：train 8693×14（有标签），test 4277×13（无标签，用于生成提交文件）。
- 正类占比 50.36%（4378/8693），类别基本平衡 → 准确率作为主指标是合理的。

## 特征工程（`src/features.py`）

28 个原始特征，编码后 42 维稠密向量，五类算法共用同一份矩阵以保证对比公平。

- 结构派生：Group、MemberNum、Deck、CabinNum、Side
- 消费派生：TotalSpend、LuxurySpend、BasicSpend、SpendTypes、NoSpend、log1p 变换
- 组内派生：GroupSize、IsAlone、GroupDeckNunique、GroupPlanetNunique、GroupSpendSum、
  GroupCryoCount、GroupAgeMean、AgeMinusGroupMean、CabinNumGroupMedian
- 耦合派生：CryoNoSpend（冷冻睡眠 ⇒ 不消费）
- 年龄段：IsChild

不使用任何标签派生的特征（例如"同组内已传送人数"），避免折叠间泄漏。
所有会学习参数的预处理都放在 Pipeline 内，只在训练折上 fit。

## 算法（5 类，原理互不相同）

| # | 算法 | 原理类别 | 归纳偏置 |
| --- | --- | --- | --- |
| 1 | 逻辑回归（L2） | 线性判别 | 特征线性可分、平滑决策边界 |
| 2 | kNN | 基于实例/距离 | 局部相似性，无全局参数假设 |
| 3 | LightGBM | 梯度提升决策树 | 轴对齐划分、特征交互、对单调变换不敏感 |
| 4 | MLP（PyTorch） | 神经网络 | 全局函数逼近、需要标准化与调参 |
| 5 | TabPFN v2 | 表格基础模型（上下文学习） | 预训练先验 + 贝叶斯式后验推断，无需梯度训练 |

## 实验协议

- 分层 5 折交叉验证（StratifiedKFold, shuffle, seed=42），OOF 预测汇总
- 3 个随机种子（42 / 2025 / 7）重复，报告 mean ± std
- 指标：Accuracy（主）、AUC、F1、Precision、Recall、Balanced Accuracy、Brier
- 显著性：以 OOF 预测做 McNemar 检验 + 折间配对 Wilcoxon 符号秩检验
- 学习曲线：训练集规模 100→6500，比较样本效率（TabPFN 论文的核心主张）
- 消融：去掉组特征 / 去掉消费派生特征，观察各算法敏感度
- 超参调优：各算法做小网格搜索（在训练折内用 inner CV）

## TabPFN 的 CPU 限制

tabpfn 9.0.0 默认禁止 CPU 上 >1000 训练样本，需 `TABPFN_ALLOW_CPU_LARGE_DATASET=1`。
论文设计范围 ≤10000 样本 / ≤500 特征，本任务 8693×28 在范围内。
耗时曲线见 `out/tabpfn_scaling.json`；若全量过慢，则主实验用全量（放开限制），
并在学习曲线实验中体现其小样本优势。
